App Review setup

JoyArk is a native iPhone client for streaming the reviewer’s own Mac on the same local network. No JoyArk login, demo account, purchase or hosted game catalog is required.

Review requirements

Use an iPhone running iOS 17 or later and a Mac running macOS 13 or later. Xcode with Swift 5.9 or later is needed to build the public Mac host. Connect both devices to the same LAN; guest Wi-Fi or client isolation may prevent discovery.

Build the companion

Download the repository ZIP, extract it, and run these commands from its folder:

./scripts/build-app.sh
open "build/JoyArk Host.app"

The source builds locally. No prebuilt notarized host or server deployment is required.

Exercise the app

  1. Grant Screen Recording to JoyArk Host. Grant Accessibility for keyboard/mouse input. Restart the host after permission changes if prompted.
  2. Choose a display and click Start Host; wait for Ready for iPhone.
  3. Open the iPhone app and allow Local Network access. Advertising permission can be declined; optional usage analytics starts disabled.
  4. Select the Mac under Nearby Macs, compare the six-digit codes, and approve on the Mac.
  5. Open an ordinary app or a game you own on the Mac, then tap Start streaming. The entire selected Mac display is streamed. Controls target the focused Mac app.
  6. Test landscape orientation, touch controls, optional system audio and 720p/1080p, 30/60 FPS options. A Bluetooth controller connected to the iPhone maps to keyboard/mouse input; native Mac gamepad emulation is not provided.
  7. Stop streaming and reconnect through Saved Macs. Forget the Mac to test a fresh pairing.

Product boundaries

Games run entirely on the user-owned Mac and remain visible there. JoyArk does not sell, download or supply games, run remote cloud computers, provide an in-app game storefront, support Windows hosts, or connect over the internet. There is no remote switch that changes app functionality during or after review.

Without a Mac, reviewers can inspect the full setup guide, local-address validation, stream settings, controller mapping, privacy choices and support pages. A Mac is required for a live stream.
