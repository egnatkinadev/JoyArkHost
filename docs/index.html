JoyArk: Cloud Gaming — setup and support

JoyArk streams games already running on your Mac to your iPhone over the same local network. It does not supply games, cloud computers, Windows support, or internet streaming. Your Mac must stay awake with JoyArk Host open.

What you need

  • A Mac running macOS 13 or later, with Xcode and Swift 5.9 or later to build the host.
  • An iPhone running iOS 17 or later with JoyArk installed.
  • Both devices on the same home network. Your Mac can use Ethernet or Wi-Fi.
  • A game you own that runs on your Mac and supports keyboard and mouse input.

Install the Mac host once

  1. Install Xcode from the Mac App Store, open it once, and finish its setup.
  2. Download the host source ZIP and unpack it.
  3. Open Terminal in the unpacked folder and run:
./scripts/build-app.sh
open "build/JoyArk Host.app"

The script builds the source on your Mac and creates a locally signed app. This is a source download, not a prebuilt notarized installer. Keep the resulting app in a stable location; you can open the same app for later sessions without rebuilding it.

Pair and play

  1. Open JoyArk Host and allow Screen Recording in macOS System Settings. Quit and reopen the host if macOS requests it.
  2. For remote controls, also allow Accessibility and enable Allow keyboard and mouse control. Video can be used without Accessibility permission.
  3. Select a display and click Start Host. Wait for Ready for iPhone.
  4. Open JoyArk on your iPhone and allow Local Network access. Select your Mac in Nearby Macs.
  5. Compare the six-digit code on both devices, then click Allow iPhone on the Mac only if they match.
  6. Start your game on the Mac, keep its window focused, and tap Start streaming on the iPhone.

The entire selected display is shared. Close private windows and notifications first. Use touch controls or a controller connected to your iPhone. The host sends keyboard and mouse input; it does not create a virtual gamepad on the Mac.

For later sessions

Open JoyArk Host, click Start Host, then choose your Mac under Saved Macs on the iPhone. No cloud deployment or relay is needed. Stopping a stream leaves the game running on your Mac; quitting the host stops its network service.

Troubleshooting

  • Mac not found: keep it awake, use the same normal network, avoid guest Wi-Fi, and allow incoming host connections through the Mac firewall. Do not forward ports through your router.
  • Black video: check Screen Recording permission and restart the host. Protected content may not be capturable.
  • No controls: check Accessibility permission, enable controls in the host, focus the game, and match its keyboard mapping to JoyArk’s Controller Mapping page.
  • Stuttering: try Ethernet for the Mac, move closer to the router, or choose 720p at 30 FPS and a lower bitrate.
  • Pairing stopped working: forget the saved Mac and pair again if its key was replaced.
